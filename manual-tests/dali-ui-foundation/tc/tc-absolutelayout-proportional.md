# AbsoluteLayout: Proportional Position / Size

`AbsoluteLayoutFlags`의 복합 값(`SIZE_PROPORTIONAL`, `ALL`, `POSITION_PROPORTIONAL`)이
부모 영역 대비 비례 위치/크기로 해석되는지 확인한다.

## 화면 구성

- 배경: 흰색(`Color::WHITE`)
- 루트: `AbsoluteLayout`, 너비/높이 모두 `MATCH_PARENT`
- 파란 박스(`Color::BLUE`): `LayoutRect(0, 0, 1.0, 1.0)` + `SIZE_PROPORTIONAL` — 루트 전체를 채움
- 빨간 박스(`Color::RED`): `LayoutRect(0.5, 0.5, 0.5, 0.5)` + `ALL` — 루트의 절반 크기로 중앙 배치
- 초록 박스(`Color::GREEN`): `LayoutRect(0.5, 0.5, 100, 100)` + `POSITION_PROPORTIONAL` — 100x100 고정 크기로 중앙 배치
- 추가 순서는 파랑 → 빨강 → 초록이다

## 테스트 1: 초기 레이아웃

1. 목록에서 본 TC에 진입한다
2. **기대 결과**: 파란 박스가 루트 전체를 빈틈없이 채운다
3. **기대 결과**: 빨간 박스가 파랑 위에 그려지며, 가로/세로 모두 루트의 절반 크기이고 중앙에 놓인다
4. **기대 결과**: 초록 박스가 빨강 위에 그려지며, 100x100 고정 크기로 중앙에 놓인다

## 테스트 2: 창 크기 변경

1. 창 크기를 가로/세로로 변경한다
2. **기대 결과**: 파란 박스는 계속 전체를 채운다
3. **기대 결과**: 빨간 박스는 항상 루트의 절반 크기를 유지하며 중앙에 남는다
4. **기대 결과**: 초록 박스는 크기가 100x100으로 고정된 채 중앙 위치만 따라 이동한다

## 통과 기준

- 나중에 추가된 자식이 먼저 추가된 자식 위에 그려져야 한다
- 창 크기를 바꾸어도 비례로 지정한 위치와 크기 비율이 유지되어야 한다
- `POSITION_PROPORTIONAL` 자식의 크기는 비례 계산의 영향을 받지 않아야 한다
