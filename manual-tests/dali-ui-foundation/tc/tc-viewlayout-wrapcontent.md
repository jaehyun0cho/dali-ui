# ViewLayout: WRAP_CONTENT

`WRAP_CONTENT` 크기를 가진 순수 `View`가 자식들이 차지하는 범위에 맞춰 축소되는지 확인한다.

## 화면 구성

- 배경은 흰색이다
- 루트: 파란색(`Color::BLUE`) `View`, 폭 `WRAP_CONTENT`, 높이 `WRAP_CONTENT`
- 자식 1: 빨간색(`Color::RED`), `50x50`, 위치 `(0, 0)`
- 자식 2: 초록색(`Color::GREEN`), `100x100`, 위치 `(100, 100)`

```
  +---------------------+
  | RED  |              |
  | 50x50|              |
  |------+--------------|
  |      | GREEN        |
  |      | 100x100      |
  +---------------------+
   루트: 200x200 (파랑)
```

## 테스트 1: 초기 레이아웃

1. 목록에서 이 TC를 선택해 화면을 관찰한다
2. **기대 결과**: 콘텐츠 영역 좌상단에 `200x200` 크기의 파란 사각형이 놓이고 나머지는 흰색이다
3. **기대 결과**: 파란 영역 좌상단에 `50x50` 빨간 박스가 붙어 있다
4. **기대 결과**: `(100, 100)` 위치에서 시작하는 `100x100` 초록 박스가 파란 영역의 우하단 모서리에 정확히 닿는다

## 테스트 2: 자식이 보이는 파란 배경

1. 파란색이 보이는 부분을 관찰한다
2. **기대 결과**: 자식이 덮지 않은 영역(우상단, 좌하단)에서만 파란 배경이 보인다

## 테스트 3: 재진입

1. `< Back`으로 목록에 나갔다가 다시 이 TC로 들어온다
2. **기대 결과**: 첫 진입과 완전히 동일한 화면이 표시된다

## 통과 기준

- 루트 파란 영역의 크기가 `200x200`이다(가장 먼 자식의 우하단 좌표 = `100 + 100`)
- 루트가 콘텐츠 영역 전체로 늘어나지 않는다
- 두 자식이 지정한 좌표와 크기 그대로 그려진다
