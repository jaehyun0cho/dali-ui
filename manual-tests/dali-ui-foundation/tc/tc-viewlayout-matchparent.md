# ViewLayout: MATCH_PARENT

`LayoutManager`가 없는 순수 `View`가 `MATCH_PARENT` 폭 / 높이로 부모 영역을 가득 채우는지 확인한다.

## 화면 구성

- 배경은 흰색이다
- 루트: 빨간색(`Color::RED`) `View` 하나, 폭 `MATCH_PARENT`, 높이 `MATCH_PARENT`

## 테스트 1: 초기 레이아웃

1. 목록에서 이 TC를 선택해 화면을 관찰한다
2. **기대 결과**: 콘텐츠 영역(상단 헤더 아래 전체)이 빈틈없이 빨간색으로 채워진다
3. **기대 결과**: 가장자리에 흰색 띠나 회색 띠가 보이지 않는다

## 테스트 2: 재진입

1. `< Back`으로 목록에 나갔다가 다시 이 TC로 들어온다
2. **기대 결과**: 첫 진입과 완전히 동일하게 콘텐츠 영역 전체가 빨간색이다

## 통과 기준

- 창 크기를 바꿔도 항상 콘텐츠 영역을 가득 채운다
- 빨간 영역의 상단은 헤더 바로 아래에, 하단 / 좌 / 우는 화면 가장자리에 닿는다
