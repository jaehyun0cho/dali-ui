# CustomLayout: Diagonal (Measure/Arrange Callback)

`Layout::SetMeasureCallback` / `Layout::SetArrangeCallback`으로 등록한 커스텀 콜백이 자식을 대각선으로 배치하는지 확인한다.

## 화면 구성

- 배경은 흰색이다
- 루트는 크기를 지정하지 않은 `Layout`이며, 콘텐츠 영역의 좌상단에 놓인다
- 루트에 `MeasureCallback`과 `ArrangeCallback`이 등록되어 있다
- 자식 3개가 추가 순서대로 배치된다
  - 자식 1: 50x50, 빨강 `Vector4(0.9, 0.2, 0.2, 1.0)`
  - 자식 2: 100x100, 초록 `Vector4(0.2, 0.7, 0.2, 1.0)`
  - 자식 3: 200x200, 파랑 `Vector4(0.2, 0.3, 0.9, 1.0)`
- `ArrangeCallback`은 자식 하나를 배치할 때마다 x와 y를 그 자식의 크기만큼 증가시킨다
- `MeasureCallback`은 자식들의 폭 합과 높이 합을 루트의 크기로 반환한다 (350x350)

```
  +--+
  |50|
  +--+----+
     |100 |
     |    |
     +----+--------+
          |  200   |
          |        |
          |        |
          +--------+
```

## 테스트 1: 초기 레이아웃

1. 목록에서 이 TC를 선택해 진입한다
2. **기대 결과**: 각 박스의 좌상단 모서리가 이전 박스의 우하단 모서리에 정확히 닿는 대각선 배치가 나타난다
3. **기대 결과**: 빨강 50x50은 (0, 0), 초록 100x100은 (50, 50), 파랑 200x200은 (150, 150)에 그려진다
4. **기대 결과**: 세 박스는 서로 겹치지 않고, 박스가 없는 영역은 모두 흰색이다

## 통과 기준

- 세 박스의 좌상단 좌표가 각각 (0, 0), (50, 50), (150, 150)이어야 한다
- 세 박스의 크기가 각각 50x50, 100x100, 200x200으로 유지되어야 한다
- 대각선으로 인접한 박스가 서로 겹치거나 벌어지지 않아야 한다
- 목록으로 나갔다가 다시 진입해도 동일한 배치가 나타나야 한다
