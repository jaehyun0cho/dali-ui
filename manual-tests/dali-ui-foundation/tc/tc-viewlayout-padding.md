# ViewLayout: Padding

순수 `View`에 설정한 padding이 자식을 안쪽으로 밀어 넣는지, 그리고 `MATCH_PARENT` / `WRAP_CONTENT` / 고정 크기 부모에서 각각 어떻게 동작하는지 확인한다.

## 화면 구성

- 배경은 흰색이다
- 루트: 회색(`Color::GRAY`) `View`, 폭 `MATCH_PARENT`, 높이 `MATCH_PARENT`
- 자식 1: 빨간색(`Color::RED`), 폭 `MATCH_PARENT`, 높이 `200px`, padding `Extents(50, 50, 50, 50)`
  - 손자: 노란색(`Color::YELLOW`), 폭 `MATCH_PARENT`, 높이 `100px`
- 자식 2: 초록색(`Color::GREEN`), 폭 `WRAP_CONTENT`, 높이 `200px`, 요청 위치 `y = 200`, padding `Extents(50, 50, 50, 50)`
  - 손자: 시안색(`Color::CYAN`), `100x100` (`MATCH_PARENT` 아님)
- 자식 3: 파란색(`Color::BLUE`), `200x200`, 요청 위치 `y = 400`, padding `Extents(50, 50, 50, 50)`
  - 손자: 마젠타(`Color::MAGENTA`), 폭 `MATCH_PARENT`, 높이 `100px`

> 상단 헤더(60px)만큼 세로 공간이 줄어들므로 최하단 요소는 창 크기에 따라 일부만 보일 수 있다.

## 테스트 1: MATCH_PARENT 부모의 padding

1. 화면 위쪽 빨간 바와 그 안의 노란 박스를 관찰한다
2. **기대 결과**: 빨간 바는 콘텐츠 영역 폭 전체를 차지하고 높이는 `200px`이다
3. **기대 결과**: 노란 박스가 빨간 바의 좌 / 우 / 상단에서 `50px`씩 안쪽으로 들어가 있고 높이는 `100px`이다

## 테스트 2: WRAP_CONTENT 부모의 padding

1. `y = 200` 위치의 초록 박스와 그 안의 시안 박스를 관찰한다
2. **기대 결과**: 초록 박스의 폭은 시안 박스 `100px` + 좌우 padding `100px` = `200px`이다
3. **기대 결과**: 시안 `100x100` 박스가 초록 박스 안쪽에서 좌 / 상단으로부터 `50px` 떨어져 놓인다

## 테스트 3: 고정 크기 부모의 padding

1. `y = 400` 위치의 파란 `200x200` 박스와 그 안의 마젠타 박스를 관찰한다
2. **기대 결과**: 마젠타 박스의 폭은 `200px` - 좌우 padding `100px` = `100px`이고 높이는 `100px`이다
3. **기대 결과**: 마젠타 박스가 파란 박스의 좌 / 상단에서 `50px` 떨어져 놓인다

## 테스트 4: 재진입

1. `< Back`으로 목록에 나갔다가 다시 이 TC로 들어온다
2. **기대 결과**: 첫 진입과 완전히 동일한 화면이 표시된다

## 통과 기준

- 세 자식 모두 자신의 padding만큼 손자를 안쪽으로 밀어 넣는다
- `MATCH_PARENT` 손자(노랑 / 마젠타)의 폭은 부모 폭에서 좌우 padding `100px`을 뺀 값이다
- `WRAP_CONTENT` 부모(초록)의 폭은 손자 폭에 좌우 padding을 더한 값으로 커진다
- 자식 2와 자식 3의 세로 위치는 각각 `y = 200`, `y = 400`이다
