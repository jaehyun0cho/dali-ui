# LayoutTransition: List Reorder (Drag)

편집 모드에서 항목을 끌어 순서를 바꿀 때, 원래 자리를 대신하는 빈 슬롯(프록시)이 따라 움직이고
형제 항목의 재배치가 `LayoutTransition`의 CHANGE 슬롯으로 애니메이션되는지 확인한다.
뷰포트 가장자리 자동 스크롤도 함께 확인한다.

## 화면 구성

- 배경은 흰색이다
- 상단: 높이 60px의 버튼 행(`FlexLayout`, `FlexDirection::ROW`, `FlexAlign::STRETCH`).
  세 버튼은 `FlexGrow 1`로 폭을 균등 분할하고 좌우 margin 5px씩으로 10px 간격이 생긴다
- 버튼은 검정 배경(`Color::BLACK`) + 흰 글씨(`Color::WHITE`)이며 라벨은 왼쪽부터
  `Click to ENTER`, `Click to EXIT`, `Click to Edit`이다
- 하단: 세로 `ScrollView`(`ScrollDirection::Vertical`, `OverScrollMode::ContentScrolls`) 안에
  세로 `StackLayout`(`WRAP_CONTENT` 높이, spacing 10px)이 들어 있다
- 진입 시 항목 12개가 각각 높이 80px, 폭 `MATCH_PARENT`로 놓이며 색은
  `Color::RED` → `Color::GREEN` → `Color::BLUE` → `Color::YELLOW` → `Color::CYAN` →
  `Color::MAGENTA` 순으로 순환한다
- 항목 수가 화면보다 많으므로 세로 스크롤이 가능하다
- ENTER / EXIT / CHANGE 세 슬롯은 0.4초 `EASE_IN_OUT_SINE` 타이밍을 공유한다

## 테스트 1: ENTER / EXIT

1. `Click to ENTER`를 누른다
2. **기대 결과**: 목록 맨 아래에 새 항목이 높이 0 → 80px 확장과 opacity 0 → 1 페이드로 추가된다
3. `Click to EXIT`를 누른다
4. **기대 결과**: 마지막 항목이 높이 수축 + 페이드아웃 후 제거되고, 나머지 항목의 재배치가
   0.4초 CHANGE로 애니메이션된다

## 테스트 2: 편집 모드 전환

1. `Click to Edit`를 누른다
2. **기대 결과**: `Click to Edit` 버튼의 배경이 검정에서 파란 계열(`(0.0, 0.35, 0.65, 1.0)`)로 바뀌고
   편집 모드로 들어간다
3. `Click to Edit`를 다시 눌러 편집 모드를 해제한 뒤, 항목을 눌러 끈다
4. **기대 결과**: 순서가 바뀌지 않고 `ScrollView`가 정상적으로 스크롤된다

## 테스트 3: 드래그 재정렬

1. 편집 모드에서 항목 하나를 눌러 위 또는 아래로 끈다
2. **기대 결과**: 누른 항목이 손가락을 따라 떠서 움직이고, 원래 자리에는 같은 크기의 빈 슬롯이 남는다
3. 계속 끌어 다른 항목의 위치를 지나간다
4. **기대 결과**: 빈 슬롯이 새 위치로 옮겨 가고 형제 항목들이 0.4초 CHANGE로 재배치된다
5. 손을 뗀다
6. **기대 결과**: 떠 있던 항목이 놓은 화면 위치에서 시작해 빈 슬롯 자리로 미끄러져 들어가며,
   순간이동 없이 이어진다

## 테스트 4: 가장자리 자동 스크롤

1. 편집 모드에서 항목을 끌어 `ScrollView` 뷰포트의 위쪽 또는 아래쪽 60px 이내로 이동시킨다
2. **기대 결과**: 손가락을 멈춰도 목록이 그 방향으로 자동 스크롤된다.
   가장자리에 가까울수록 스크롤 속도가 빨라진다(최대 한 틱당 12px)
3. 자동 스크롤 중 손가락을 그대로 둔다
4. **기대 결과**: 내용이 밀려 올라가/내려가면서 빈 슬롯 위치도 계속 재계산되어,
   화면 밖에 있던 위치까지 순서를 옮길 수 있다
5. 손가락을 가장자리 밖(60px 이상 안쪽)으로 되돌린다
6. **기대 결과**: 자동 스크롤이 멈춘다

## 테스트 5: 드래그 도중 뒤로 가기

1. 편집 모드에서 항목을 끌고 있는 상태로(손을 떼지 않고) `< Back`을 눌러 목록으로 나간다
2. 다시 이 TC로 들어온다
3. **기대 결과**: 편집 모드가 해제된 상태(버튼 배경 검정)이고 항목 12개가 처음 순서대로 놓여 있다
4. **기대 결과**: 화면 어디에도 떠 있던 항목이 남아 있지 않고, 빈 슬롯도 남지 않는다
5. 목록 화면으로 돌아가 다른 TC를 열어 본다
6. **기대 결과**: 이전 TC의 항목이 겹쳐 보이지 않는다

## 통과 기준

- 편집 모드에서만 드래그 재정렬이 시작되어야 한다
- 드래그 중 원래 자리에 남는 빈 슬롯이 손가락을 따라 이동하고, 형제 항목 재배치가
  0.4초 `EASE_IN_OUT_SINE` CHANGE로 애니메이션되어야 한다
- 항목을 집거나 놓는 순간에 항목이 순간이동하거나 형제가 튀지 않아야 한다
- 뷰포트 위/아래 60px 이내에서 자동 스크롤이 동작하고, 그동안에도 순서 재계산이 계속되어야 한다
- 드래그 중 뒤로 가기 후 재진입해도 화면에 떠 있는 잔여 뷰가 없어야 한다
- 목록으로 나갔다 다시 들어오면 항상 편집 모드 해제 · 항목 12개 초기 순서로 초기화되어야 한다
