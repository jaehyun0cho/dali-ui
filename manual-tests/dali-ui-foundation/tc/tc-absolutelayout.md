# AbsoluteLayout: Absolute Position

`AbsoluteLayout`이 자식을 명시적인 픽셀 좌표와 크기에 배치하는지 확인한다.

## 화면 구성

- 배경: 흰색(`Color::WHITE`)
- 루트: `AbsoluteLayout`, 너비/높이 모두 `MATCH_PARENT`
- 빨간 박스(`Color::RED`): `LayoutRect(50, 50, 50, 50)` — 좌상단에서 (50, 50) 위치에 50x50
- 초록 박스(`Color::GREEN`): `LayoutRect(100, 100, 100, 100)` — (100, 100) 위치에 100x100
- 파란 박스(`Color::BLUE`): `LayoutRect(200, 200, 100, 50)` — (200, 200) 위치에 100x50

```
  +---------------------------
  |  [빨강 50x50]
  |       [초록 100x100]
  |            [파랑 100x50]
```

## 테스트 1: 초기 레이아웃

1. 목록에서 본 TC에 진입한다
2. **기대 결과**: 빨간 박스가 (50, 50)에 50x50 크기로 표시된다
3. **기대 결과**: 초록 박스가 (100, 100)에 100x100 크기로 표시된다
4. **기대 결과**: 파란 박스가 (200, 200)에 100x50 크기로 표시된다
5. **기대 결과**: 박스가 없는 영역은 모두 흰색으로 표시된다

## 통과 기준

- 세 박스가 각각 지정한 좌표와 크기에 정확히 배치되어야 한다
- 세 박스는 서로 겹치지 않아야 한다
- 배경은 흰색(`Color::WHITE`)이어야 한다
- 목록으로 나갔다가 다시 진입해도 동일한 화면이 표시되어야 한다
