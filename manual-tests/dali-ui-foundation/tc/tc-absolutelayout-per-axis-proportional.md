# AbsoluteLayout: Per-axis Proportional Flags

`AbsoluteLayoutFlags`를 축 하나씩만 지정했을 때 해당 축만 비례로 계산되고
나머지 축은 절대값으로 유지되는지 확인한다.

## 화면 구성

- 배경: 흰색(`Color::WHITE`)
- 루트: `AbsoluteLayout`, 너비/높이 모두 `MATCH_PARENT`, 배경 `Color::GAINSBORO`
- 노란 박스(`Color::YELLOW`): `LayoutRect(0, 100, 100, 0.5)` + `HEIGHT_PROPORTIONAL`
  — x=0, y=100, 너비 100px 고정, 높이는 루트 높이의 50% (왼쪽 세로 띠)
- 파란 박스(`Color::BLUE`): `LayoutRect(100, 0, 0.5, 100)` + `WIDTH_PROPORTIONAL`
  — x=100, y=0, 너비는 루트 너비의 50%, 높이 100px 고정 (위쪽 가로 띠)
- 빨간 박스(`Color::RED`): `LayoutRect(1.0, 0, 100, 100)` + `X_PROPORTIONAL`
  — x는 `(루트 너비 - 100) * 1.0`이므로 오른쪽 끝, 100x100 (우상단)
- 초록 박스(`Color::GREEN`): `LayoutRect(0, 1.0, 100, 100)` + `Y_PROPORTIONAL`
  — y는 `(루트 높이 - 100) * 1.0`이므로 아래쪽 끝, 100x100 (좌하단)

## 테스트 1: 초기 레이아웃

1. 목록에서 본 TC에 진입한다
2. **기대 결과**: 루트 배경이 `Color::GAINSBORO`(연회색)로 표시된다
3. **기대 결과**: 노란 띠가 왼쪽에서 y=100부터 시작하며 높이가 루트 높이의 절반이다
4. **기대 결과**: 파란 띠가 위쪽 x=100부터 시작하며 너비가 루트 너비의 절반이다
5. **기대 결과**: 빨간 박스가 오른쪽 위 모서리에 100x100으로 붙어 있다
6. **기대 결과**: 초록 박스가 왼쪽 아래 모서리에 100x100으로 붙어 있다

## 테스트 2: 창 크기 변경

1. 창 너비를 늘리거나 줄인다
2. **기대 결과**: 파란 띠의 너비만 루트 너비의 50%로 따라 변하고 높이는 100px로 유지된다
3. **기대 결과**: 빨간 박스는 크기 변화 없이 오른쪽 모서리에 계속 붙어 있다
4. 창 높이를 늘리거나 줄인다
5. **기대 결과**: 노란 띠의 높이만 루트 높이의 50%로 따라 변하고 너비는 100px로 유지된다
6. **기대 결과**: 초록 박스는 크기 변화 없이 아래쪽 모서리에 계속 붙어 있다

## 통과 기준

- 창 크기를 바꾸면 비례 플래그를 지정한 축만 값이 변해야 한다
- 절대값으로 지정한 축은 창 크기와 무관하게 값이 유지되어야 한다
- 네 자식은 400x400 이상 크기에서 서로 겹치지 않아야 한다
