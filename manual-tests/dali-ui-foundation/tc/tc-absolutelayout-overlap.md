# AbsoluteLayout: Overlap / Z-order

`AbsoluteLayout`의 자식이 자유롭게 겹칠 수 있고, 나중에 추가된 자식이 위에 그려지는지 확인한다.

## 화면 구성

- 배경: 흰색(`Color::WHITE`)
- 루트: `AbsoluteLayout`, 너비/높이 모두 `MATCH_PARENT`
- 빨간 박스(`Color::RED`): `LayoutRect(50, 50, 400, 400)` — 가장 큰 배경 박스
- 초록 박스(`Color::GREEN`): `LayoutRect(100, 100, 200, 200)` — 빨강과 겹침
- 파란 박스(`Color::BLUE`): `LayoutRect(200, 200, 100, 100)` — 빨강/초록과 겹침
- 시안 박스(`Color::CYAN`): `LayoutRect(0.5, 0.5, 50, 50)` + `POSITION_PROPORTIONAL` — 50x50 고정 크기로 중앙 배치
- 추가 순서는 빨강 → 초록 → 파랑 → 시안이다

## 테스트 1: 초기 레이아웃

1. 목록에서 본 TC에 진입한다
2. **기대 결과**: 400x400 빨간 박스가 (50, 50)에 표시된다
3. **기대 결과**: 200x200 초록 박스가 (100, 100)에서 빨강 위에 그려진다
4. **기대 결과**: 100x100 파란 박스가 (200, 200)에서 초록 위에 그려진다
5. **기대 결과**: 50x50 시안 박스가 콘텐츠 영역 중앙에 가장 위로 그려진다

## 테스트 2: 창 크기 변경

1. 창 크기를 변경한다
2. **기대 결과**: 절대 좌표를 쓰는 빨강/초록/파랑의 위치와 크기는 그대로 유지된다
3. **기대 결과**: 시안 박스만 중앙을 따라 이동하고 크기는 50x50으로 유지된다

## 통과 기준

- 자식이 서로 겹쳐 그려져야 하며 잘리지 않아야 한다
- 겹침 순서(Z-order)가 추가 순서와 정확히 일치해야 한다
- 목록으로 나갔다가 다시 진입해도 동일한 화면이 표시되어야 한다
