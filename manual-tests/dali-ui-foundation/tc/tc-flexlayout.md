# FlexLayout: Row + FlexGrow

`FlexDirection::ROW` 컨테이너에서 고정 폭 자식과 `SetFlexGrow` 자식이 가로 공간을 나누는 방식을 확인한다.

## 화면 구성

- 배경은 흰색(`Color::WHITE`)이다.
- 루트는 `MATCH_PARENT x MATCH_PARENT` 크기의 `FlexLayout`이며 `FlexDirection::ROW`, `FlexAlign::STRETCH`, padding `Extents(50, 50, 50, 50)`가 설정된다.
- 자식은 추가된 순서대로 세 개다.
  - 빨강(`Color::RED`): 폭 100px 고정
  - 초록(`Color::GREEN`): 폭 `WRAP_CONTENT` + `FlexLayoutParams::New().SetFlexGrow(1.0f)`
  - 파랑(`Color::BLUE`): 폭 100px 고정

```
  +-- padding 50 --------------------------------------+
  | [red 100] [green : flex-grow 1        ] [blue 100] |
  +----------------------------------------------------+
```

## 테스트 1: 초기 레이아웃

1. 목록에서 이 TC를 선택한다
2. **기대 결과**: 왼쪽부터 빨강 → 초록 → 파랑 순으로 세 박스가 가로로 나란히 배치된다
3. **기대 결과**: 빨강과 파랑의 폭은 각각 100px이고, 초록이 남은 가로 공간을 모두 차지한다
4. **기대 결과**: 네 방향 모두 50px padding이 유지되어 박스들이 콘텐츠 영역 가장자리에서 50px 안쪽에 놓인다
5. **기대 결과**: `FlexAlign::STRETCH`에 의해 세 박스의 높이가 padding 안쪽 세로 영역 전체로 늘어난다

## 테스트 2: 창 크기 변경

1. 창의 가로 크기를 늘리거나 줄인다
2. **기대 결과**: 빨강과 파랑의 폭은 100px 그대로 유지된다
3. **기대 결과**: 초록의 폭만 변화량만큼 늘거나 줄어든다

## 통과 기준

- 빨강과 파랑의 폭이 항상 100px여야 한다
- 초록의 폭이 `콘텐츠 영역 폭 - 100(padding) - 200(고정 폭 두 개)`이어야 한다
- 세 박스 사이에 빈 간격이 없어야 한다
- 배경이 회색이 아닌 흰색으로 보여야 한다
