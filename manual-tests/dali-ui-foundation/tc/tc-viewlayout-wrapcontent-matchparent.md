# ViewLayout: MATCH_PARENT under WRAP_CONTENT

`WRAP_CONTENT` 부모 안에서 `MATCH_PARENT` 자식이 "따라가는(follower)" 크기로 결정되는지 확인한다. 즉 부모 크기는 고정 크기 자식이 결정하고, `MATCH_PARENT` 자식은 그렇게 정해진 부모 크기에서 자신의 margin을 뺀 크기가 된다.

## 화면 구성

- 배경은 흰색이다
- 루트: `Color::GAINSBORO` `View`, 폭 `WRAP_CONTENT`, 높이 `WRAP_CONTENT`
- 자식 1: 빨간색(`Color::RED`), `300x300` 고정, margin `Extents(50, 50, 50, 50)` → 루트를 `400x400`으로 만든다
- 자식 2: 초록색(`Color::GREEN`), 폭 / 높이 `MATCH_PARENT`, margin `Extents(100, 100, 100, 100)` → `200x200`
  - 손자: 파란색(`Color::BLUE`), 폭 / 높이 `MATCH_PARENT`, margin `Extents(50, 50, 50, 50)` → `100x100`
- 순수 `View`는 자식을 겹쳐 놓으므로 초록과 파랑은 빨강 위에 그려진다

## 테스트 1: 초기 레이아웃

1. 목록에서 이 TC를 선택해 화면을 관찰한다
2. **기대 결과**: 콘텐츠 영역 좌상단에 `400x400` 크기의 영역이 잡히고, 그 안쪽 `(50, 50)`부터 `300x300` 빨간 박스가 보인다
3. **기대 결과**: 빨간 박스 위에 `200x200` 초록 박스가 겹쳐 보인다
4. **기대 결과**: 초록 박스 위에 `100x100` 파란 박스가 겹쳐 보인다

## 테스트 2: MATCH_PARENT 자식의 크기 계산

1. 초록과 파랑의 크기를 관찰한다
2. **기대 결과**: 초록 = 루트 `400x400` - margin `100`씩 양쪽 = `200x200`
3. **기대 결과**: 파랑 = 초록 `200x200` - margin `50`씩 양쪽 = `100x100`

## 테스트 3: 재진입

1. `< Back`으로 목록에 나갔다가 다시 이 TC로 들어온다
2. **기대 결과**: 첫 진입과 완전히 동일한 화면이 표시된다

## 통과 기준

- 루트가 콘텐츠 영역 전체가 아니라 `400x400`으로 축소된다(고정 크기 자식 `300` + margin `50` x 2)
- `MATCH_PARENT` 자식이 부모를 다시 키우지 않는다
- 초록 / 파랑의 상하좌우 여백이 각 축에서 서로 같다
